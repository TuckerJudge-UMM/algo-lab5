# algo-lab5
Source:
https://en.wikipedia.org/wiki/Gale%E2%80%93Shapley_algorithm

This algorithm follows the Gale-Shipley Algorithm, where all programmers receive their best possible match. Because all companies have offers to all programmers and all programmers have ranked choices for companies, then their exists a valid pair of size n.

This algorithm will assess all possible pairs in the worst case making it O(n^2) where n is the size of both matrices.
